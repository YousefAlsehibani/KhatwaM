# خطوة · المتوسط

منصة متابعة الإنجاز الأسبوعي لطلاب المرحلة المتوسطة: مقرر أسبوعي لكل صف، تسجيل يومي مربوط بفائدة مكتوبة، ومنتخبات يختارها المشرف التنفيذي.

## التشغيل محليًا

الملفات ثابتة بلا أي بناء أو تثبيت حزم:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا (مثلًا `khutwah-mutawassit`).
2. ارفع محتويات هذا المجلد في **جذر** المستودع — لا داخل مجلد فرعي.
3. من `Settings` ← `Pages`:
   - Source: **Deploy from a branch**
   - Branch: `main` والمجلد `/ (root)`
4. الرابط يظهر خلال دقيقة تقريبًا:
   `https://<اسم-الحساب>.github.io/khutwah-mutawassit/`

ملف `.nojekyll` موجود لتعطيل معالجة Jekyll، وبدونه قد يتجاهل GitHub بعض الملفات.

## ملاحظات هندسية

- **فهرسة مسبقة:** تُبنى خرائط (طالب+يوم)، (طالب)، (أسبوع)، والفوائد بالطالب وبالصف مرة واحدة عند التحميل، فلا تُمسح السجلات في كل عرض. القياس على ٣٩ ألف سجل و٤٥٠ طالبًا: الفهرسة ٢٨٠ مللي مرة واحدة، ولوحة المشرف ١٤ مللي.
- **تحميل تدريجي:** بطاقات الطلاب والفوائد تُعرض ٢٤ في كل مرة، وصفوف المصفوفة ٣٠، مع زر «عرض المزيد» — يمنع بناء آلاف العناصر دفعة واحدة.
- **حركة عند الظهور:** العناصر تتحرك حين تدخل مجال الرؤية عبر `IntersectionObserver`، ولا تُرسم الأشرطة والأرقام قبل ذلك.
- **بلا مكتبات خارجية:** لا إطار عمل ولا حزم — الحجم الكلي ٩٥ كيلوبايت غير مضغوطة، ويصل نحو ٢٥ كيلوبايت بعد ضغط GitHub التلقائي.
- **الخطوط** من Google Fonts مع `preconnect` و`display=swap`؛ لو انقطع الاتصال بها يعود المتصفح لخط النظام دون كسر التصميم.
- **البيانات في الذاكرة فقط**، وتُفقد مع تحديث الصفحة. الخطوة التالية ربطها بـ Supabase.
